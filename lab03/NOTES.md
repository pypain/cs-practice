##сравнение версий и поиск изменений

`git log --oneline --stat` показывает историю коммитов и какие файлы менялись в каждом коммите.

`git diff HEAD~2 HEAD -- lab03/calc.py` сравнивает две версии файла и показывает, какие строки были добавлены или удалены.

`git show HEAD~1` показывает конкретный коммит и изменения, которые были сделаны в нём.

`git log` показывает историю коммитов, `git diff` сравнивает две версии, а `git show` показывает информацию и изменения конкретного коммита.

`git log -S"def" --oneline -- lab03/calc.py` ищет коммиты, в которых добавлялись или удалялись строки с `def`. в моём файле `def` не было, поэтому команда ничего не показала.

`git blame lab03/calc.py` показывает для каждой строки файла, в каком коммите она последний раз изменялась. по нему видно, какие строки появились при добавлении сложения, вычитания и умножения.

##восстановление файла

`git restore lab03/calc.py` возвращает файл в состояние последнего коммита и удаляет мои незакоммиченные изменения.

`git restore --source=HEAD~2 lab03/calc.py` берёт файл не из последнего коммита, а из более старого состояния проекта.

если в файле были мои незакоммиченные правки, то после `git restore` они пропадут.

#лабораторная работа 2

##состояние git

рабочая папка - файлы проекта в том виде, в котором я их редактирую.

индекс - область подготовки файлов, там хронятся изменнения, которые будут в следующем коммите.

коммит - точка в истории проекта с подготовленными изменениями

##git и github

git - локальная система контроля версий, файлы сохраняются локально

github - онлайн платформа, которая позволяет хранить git репозитории и публиковать их.

'git diff' - сравнивает рабочую папку с индексом, показывает изменения, которые еще не добавили через 'git add'

'git diff --staged' сравнивает индекс с последним коммитом, показывает подготовленные изменения

##использованные команды

'git status' показывает текущую ветку и состояние файлов: какие изменены, подготовлены или ещё не отслеживаются.

`git diff` показывает изменения в рабочей папке, которые не добавлены в индекс

`git diff --staged` показывает изменения, добавленные в индекс и готовые к коммиту

##ветки

ветка - отдельная линия разработки проекта, когда в ветке создаётся новый коммит, указатель этой ветки перемещается на созданный коммит.
слияние объединяет изменения из одной ветки с другой, после слияния изменения из ветки становятся частью основной ветки.
